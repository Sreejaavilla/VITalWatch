# Curated term subset — Sreeja

Not MedDRA. Not WHODrug. A hand-built stand-in with the same *shape*.

* `terms.csv`  — ~200 rows: `code,llt,pt,soc` (Ayurveda-trial-plausible AEs)
* `drugs.csv`  — ~40 rows: `code,drug_name,class` (ASU&H formulations)

Enough coverage that every AE in the synthetic portfolio codes to something, and
enough breadth that a judge typing free text into the demo gets a sensible hit.
