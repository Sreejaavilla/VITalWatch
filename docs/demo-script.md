## The path — never deviate from it on stage

1. **Login as PI** — role-based landing, not a generic homepage
2. **Portfolio** — 6 live KPIs across 8 studies. Point at the two lagging enrolment.
3. **Alert** — click the enrolment-lag alert, land inside the offending study
4. **Study drill-down** — enrolment vs target curve, site table, visit compliance, open queries
5. **Switch to PV role** — file an SAE, watch it code the free-text narrative, watch the
   24-hour clock start
6. **DSMB signal view** — one term over-represented in one arm
7. **Switch to regulator** — read-only. Try to mutate something. Show the 403.
8. **Audit trail** — every action from the last 3 minutes, with before/after and actor.
   Press **verify chain**. Green.
9. **Close:** "that's one auditable view of the whole lifecycle, and nothing in it can be
   quietly edited."
