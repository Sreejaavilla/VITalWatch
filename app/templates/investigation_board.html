What the second retriever is, and is not

It is not a dense vector model. Real dense retrieval embeds the query at request time, which means shipping a neural model; this build has none, and calling a lexical retriever “semantic” would be the same overclaim as calling terms.csv MedDRA.

What it does is real and independent: it expands the query through the curated vocabulary, so a query reaches documents sharing no words with it. Try deranged LFT — BM25 returns nothing, because those words appear in no document; concept expansion returns eight, because the phrase resolves to the same controlled term the corpus discusses as “transaminase”. It is also the vocabulary the adverse-event coder uses, so the retriever and the coder cannot disagree about what a term means.

Swapping in embeddings replaces one function. rrf() consumes ranked lists and does not care where they came from.
